🍔 Hamburgueria Dramaticos
<br>
<br>
Este é um projeto de interface de cardápio digital para uma hamburgueria, focado em manipulação dinâmica de elementos usando JavaScript.
<br>
<br>
🚀 Tecnologias Utilizadas
HTML5: Estruturação da página.

CSS3: Estilização e layout responsivo.

JavaScript (ES6+): Lógica de filtragem, cálculos de preços e renderização dos produtos.
<br>

🛠️ Funcionalidades
Listagem Dinâmica: Os produtos são gerados via JavaScript, facilitando a manutenção.

Filtros de Categoria: Botões para filtrar produtos (ex: Vegetarianos).

Cálculo de Desconto: Função que aplica 10% de desconto em todos os itens.

Soma do Carrinho: Exibe o valor total de todos os itens do cardápio usando o método reduce.
